# `@jerekode/tui`

Minimal owned Bun TUI started by bare `jerekode` (no subcommand).

- Interactive prompt loop (MVP echo)
- `JEREKODE_TUI_SMOKE=1` — print banner and exit (CI / CLI smoke)
- `JEREKODE_SERVER_URL` — optional health check target

Not a port of OpenCode's TUI; owned surface for drop-in bare invoke.
